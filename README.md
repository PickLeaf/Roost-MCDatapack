# 前置 & Dependency
You need to install the [Nutlet](https://github.com/PickLeaf/Nutlet-MCDatapack) Datapack first in order to correctly create the multiblock structure machine for this datapack.<br>
你需要先安装[Nutlet](https://github.com/PickLeaf/Nutlet-MCDatapack)数据包才能正确创建本数据包的多方块结构机器。
# Minecraft Datapack
The Roost be added to produce eggs without terrible lag.
The Chicken Incubator be added to turn Egg into adult Chicken.
# 我的世界数据包
添加了鸡窝，能够低卡顿产出鸡蛋。
添加了鸡孵化器，把鸡蛋孵化成大鸡。
